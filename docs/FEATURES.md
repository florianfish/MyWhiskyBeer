# Idées de fonctionnalités

Priorité : **P1** = MVP, **P2** = rapidement après, **P3** = un jour peut-être.

## Saisie
| Fonctionnalité | Priorité |
|---|---|
| Création rapide d'un produit (nom, producteur, type, degré) | P1 |
| Photo de la bouteille / du verre | P1 |
| Autocomplétion sur les producteurs, styles et distilleries déjà saisis | P1 |
| Dupliquer une dégustation pour re-noter le même produit | P1 |
| Scan du code-barres + Open Food Facts | P2 |
| OCR de l'étiquette (nom, degré, âge) | P2 |
| Dictée vocale pour les commentaires | P3 |

## Notation
| Fonctionnalité | Priorité |
|---|---|
| Note globale : sur 5 pour la bière, sur 100 pour le whisky | P1 |
| Nez / bouche / finale (texte libre) | P1 |
| Roue d'arômes à cocher, propre à chaque type | P1 |
| Intensité par arôme (léger / marqué / dominant) | P2 |
| Notes détaillées : corps, amertume, sucrosité, longueur, tourbe (curseurs) | P2 |
| Conditions de service (eau, glace, température, verre) | P2 |
| Mode dégustation à l'aveugle | P3 |
